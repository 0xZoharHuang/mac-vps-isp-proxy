# 服务端、安全与运维

## 部署契约，不是自动安装命令

1. 记录监听、服务、路由、防火墙和管理路径。UDP 443 与 TCP 443 分开检查，不能替换已有 SSH/sslh/Caddy。
2. 锁定 sing-box 发行版本/校验值，用该版本 `sing-box check -c <candidate.json>`。历史用过 1.13.18，不表示它仍是最新或无漏洞版本。
3. Hysteria2/AnyTLS 入站按设备/使用组独立凭据；需故障隔离可独立 unit/端口，不必每设备新建 VPS。
4. SOCKS5 出站指向 ISP，final 指向该出口，无公网 direct fallback。拒绝外部入站访问服务器私网/管理目标，避免内网跳板；按锁定版本明确 DNS 行为。
5. 套餐支持时使用 VPS 源 IP 白名单，无需保存 ISP 密码。否则按供应商认证要求存入受限服务端文件；不假设所有套餐都支持白名单、多来源或 UDP。
6. 专用无登录用户，受限目录/密钥，NoNewPrivileges、ProtectSystem、PrivateTmp、资源限额；只授必要 bind capability。用真实协议验证沙箱没有阻断功能。
7. 先解析/回环，再经批准放行精确端口、启动独立入口；显式代理通过后才接管设备。失败只停新增服务，保留管理与其他用户路径。

本地研发目录 `personal-vpn/ServerDeployment/` 是 Hysteria2 候选材料，未随本次文档发布，不覆盖全部后续 AnyTLS 部署。离线通过不是上线证明；不要把它当成远端仓库已有的部署工具。

## TLS、秘密与发布

- 客户端仅拿自己的接入密码，不拿 VPS SSH 私钥、ISP 账号或别人的凭据。
- 日志只记错误类别、耗时、脱敏身份，不打印配置/订阅/认证头。
- Surge `server-cert-fingerprint-sha256` 与 mihomo `fingerprint` 使用证书摘要，旧原生候选 SPKI 不可混用。
- 轮换前确认客户端多 pin 能力，不能臆造语法。单 pin 客户端用独立入口/受控窗口迁移，不能为方便关闭验证。
- 证书所有副本记录到期日、位置、拥有者和替换流程；复制到第二服务不等于自动续期。
- 生产配置留在仓库外。发布前扫描待提交 diff 与历史；发现旧秘密先撤销/轮换，历史重写另行批准。不能靠删除当前文件消除已泄露凭据。

## 容量

独立入口/密码不等于独立 ISP、流量额度或性能。分别看 VPS CPU/内存、VPS 带宽/计费、ISP 订单流量池/并发/限制、客户端至 VPS 质量。一次下载耗时不是吞吐上限。

先核对当前订单，再决定补流量、增加固定 ISP 或备用 VPS；多个 VPS 共享同一个被限速 ISP 不能解决上游瓶颈。备用 VPS 需验证供应商白名单/多来源政策。固定业务身份不应随机轮换 IP。价格和政策不写死在模板里。

实名限制、站点风控和区域政策会变化。403 不能直接判“线路健康”或“代码错误”，要看响应来源与真实业务；核心 Google/GPT 不可用时不交付为健康。

## 分层排障

| 层 | 检查 |
|---|---|
| 接管 | 活动配置/模式、默认路由/DNS、终端旧代理变量 |
| 解析 | 真地址还是旧 Fake-IP、有效 DNS 是否混入系统解析 |
| 入口 | TCP/UDP 可达、认证/pin、重连、丢包、资源限制 |
| VPS→ISP | 白名单/账号、TCP/UDP、目标分别可达 |
| 业务 | 响应来自谁、登录/长连接/图片是否真实成功 |

同一目标通过受限显式代理做分层对照，不盲改 MTU/DNS，不偷偷变成 VPS 直出。故障注入仅在获准独立入口操作，不能停共享服务影响别人。

官方参考：[sing-box SOCKS](https://sing-box.sagernet.org/configuration/outbound/socks/)、[AnyTLS inbound](https://sing-box.sagernet.org/configuration/inbound/anytls/)。
