# 迁移与验收

以下是先前现场工作摘要，**不是 2026-10-21 重测**，不是任意设备复制就通过的保证。

| 历史路径 | 曾记录的检查 | 不代表 |
|---|---|---|
| Surge Mac 6.0.1 / Hysteria2 | 规则模式、默认终端与显式代理出口、多目标、微信 DIRECT 命中 | 所有图片/小程序可用、长期无中断 |
| FlClash Mac 0.8.92 / AnyTLS | 后续 TUN/DNS 调试与批量请求、退出恢复；早期仅系统代理成功 | 早期成功已覆盖终端，所有新版本相同 |

本次仅整理文档/片段，未重测现场。早晚阶段记录不同，不能用旧成功或旧失败替代当前验收。

## 每台新设备都要做

- [ ] 记录 OS、客户端/核心版本、时间、授权范围、预期 ISP 出口。
- [ ] 备份原配置，记录路由、物理 DNS、系统代理、启动项；不全局重置网络。
- [ ] 保留维护路径与失联恢复人；独立配置导入并通过实际客户端解析。
- [ ] 核对 GUI 有效配置，单控制器、无隐式回退，明确直连例外。
- [ ] 显式代理请求和**不带代理参数的新终端请求**均检查出口。
- [ ] Google 204、OpenAI API 未认证 401、GitHub/Apple 分别验证响应来源；401 不代表 ChatGPT 登录/Codex 长连接验收。
- [ ] 独立测试 TCP、真实 UDP relay（如受控 STUN）、DNS 路径；DNS 成功不等于 UDP 业务通过。
- [ ] 原始 IPv6、AAAA、路由、实际出口分别检查；禁 AAAA 不等于无泄漏。
- [ ] 浏览器、Git、原生 App、微信图片/小程序分别人工验收；记录直连例外。
- [ ] 经预算批准做并发、至少 10 分钟长连接、Wi-Fi 重连、睡眠唤醒、真实重启。
- [ ] 获准独立入口故障注入，确认无静默换 IP；记录核心退出/崩溃后行为。
- [ ] 停止客户端后按基线确认路由/DNS/代理恢复、维护正常、原订阅不变。
- [ ] 手动切回原配置，无后台自动切换与用户竞争。

## 清理与交付

新路径验收且用户批准后，按精确清单清理旧 PersonalVPN App、daemon、CLI、独立 sing-box、启动项/socket。凭据按归属识别，不通配删除所有 VPN。保留仓库源码不等于机器已卸载，备份也不能公开。

不恢复旧自动回退。发布记录应填写：日期、授权、版本、源/有效配置脱敏摘要、预期/实际出口、每项结果/耗时/证据位置、直连例外、停止恢复/重启/故障注入结果、未验证项和用户业务验收。不能把检查单直接勾满。
